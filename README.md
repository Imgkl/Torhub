# TorHub x Raycast

Search and get torrents right from Raycast

> [!NOTE]
> This extension is not affiliated with or endorsed by the creators of the websites it uses.
> It is a third-party tool that uses the websites' APIs to search for torrents.
> The creators of this extension are not responsible for the content of the websites it uses.
> Use at your own risk.

> [!IMPORTANT]
> According to Raycast, I can't publish this extension to the Raycast store. Because it provides  easy access to content that is regarded as illegal and blocked in some countries.
> 
> You can still download the repo and import the extension in Raycast.
